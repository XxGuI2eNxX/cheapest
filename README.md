# เปรียบเทียบราคาต่อหน่วย (Unit Price Compare)

เว็บแอปไฟล์เดียว (`index.html`) สำหรับเทียบความคุ้มของสินค้า รองรับ

- **หน่วยใหญ่** (แพ็ค/ห่อ/กล่อง) และ **หน่วยเล็ก** (ชิ้น/ซอง) ตั้งชื่อหน่วยเองได้
- **โปรโมชั่น** ซื้อ X แถม Y เช่น 2 แถม 1, 3 แถม 1
- ขนาดต่อชิ้น (กรัม/มล.) เพื่อเทียบราคาต่อ 100 ก./มล.
- จัดอันดับถูกไปแพง บอก % ที่แพงกว่าตัวถูกสุด
- ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ ไม่มี backend

## สูตร

```
จำนวนหน่วยใหญ่ที่ได้ = ซื้อ + แถม
ราคาต่อหน่วยใหญ่     = ราคา × ซื้อ ÷ (ซื้อ + แถม)
ราคาต่อหน่วยเล็ก     = ราคาต่อหน่วยใหญ่ ÷ จำนวนหน่วยเล็กต่อหน่วยใหญ่
ราคาต่อ 100 ก./มล.   = ราคาต่อหน่วยเล็ก ÷ ขนาด × 100
```
